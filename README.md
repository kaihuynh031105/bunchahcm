# 🥢 Bún Chả Hà Nội Chính Gốc – Đến Với Sài Gòn
> *"Hương vị Thủ đô giữa nhịp sống sôi động Nam Bộ"*

Landing page bán hàng và đặt bàn online hiện đại dành cho quán Bún Chả Hà Nội than hoa chính gốc, tọa lạc tại trung tâm Quận 1, TP. Hồ Chí Minh. Dự án kết hợp hài hòa giữa nét ẩm thực tinh tế, than hoa đượm khói của người Hà Nội và phong cách sống sôi nổi, năng động của Sài Gòn.

---

## 🎨 Ý Tưởng & Phong Cách Thiết Kế

- **Bảng màu chủ đạo**:
  - **Đỏ than (Charcoal Ember)**: `#C83823`, `#D32F2F`, `#FF5722` — tượng trưng cho bếp than hồng rực lửa, những miếng chả nướng xém cạnh thơm nức mũi và năng lượng nhiệt huyết của Sài Gòn.
  - **Vàng nhạt / Hoàng kim (Warm Gold & Cream Amber)**: `#FFF8E7`, `#FEF3C7`, `#F59E0B` — gợi màu nước mắm cốt pha chua ngọt ấm nóng, giọt mật ong ướp thịt và ánh đèn đêm lung linh.
  - **Xám khói / Than củi (Charcoal Smoke)**: `#121214`, `#1C1C20`, `#27272A`, `#71717A` — tái hiện làn khói than hoa đặc trưng của phố cổ Hàng Mành.
- **Typography & Font Tiếng Việt**: Sử dụng bộ font `Source Sans 3` hiện đại, thanh thoát phối hợp cùng `Playfair Display` cổ điển, sang trọng hỗ trợ 100% tiếng Việt có dấu.
- **Biểu tượng (Iconography)**: Hệ thống icon SVG vector nhẹ tênh, sắc nét, không phụ thuộc thư viện nặng ngoài mạng.
- **Thiết kế Mobile-First**: Tương thích mượt mà trên tất cả thiết bị (Mobile iPhone/Android, Tablet, Laptop, Màn hình Desktop lớn).

## 🚀 Hướng Dẫn Cài Đặt & Chạy Website

### Cách 1: Chạy bằng Node.js Server (Khuyên Dùng)

1. Cài đặt các thư viện kiểm thử (nếu chưa cài):
   ```bash
   npm install
   ```

2. Khởi động máy chủ web cục bộ:
   ```bash
   npm start
   ```
   Hoặc:
   ```bash
   node server.js
   ```

3. Mở trình duyệt web và truy cập địa chỉ:
   ```
   http://localhost:3000
   ```

---

### Cách 2: Mở Trực Tiếp Trên Trình Duyệt

Vì website sử dụng kiến trúc thuần chuẩn **HTML5, CSS3, JavaScript**, bạn chỉ cần:
- Nhấp đúp chuột trực tiếp vào tập tin `index.html` trong thư mục dự án để mở ngay trên bất kỳ trình duyệt nào (Chrome, Edge, Firefox, Safari) mà không bắt buộc phải bật máy chủ!

---

### Cách 3: Sử dụng Python HTTP Server

Nếu máy bạn đã cài sẵn Python:
```bash
python -m http.server 3000
```
Sau đó truy cập: `http://localhost:3000`

## 🧪 Chạy Kiểm Thử Tự Động (Automated Testing)

Dự án tích hợp kịch bản kiểm thử tự động toàn diện bằng **Playwright**:
- Tự động mở trình duyệt Chromium / Microsoft Edge
- Chụp ảnh màn hình toàn trang Desktop (`screenshot-fullpage.png`)
- Chuyển chế độ Mobile View (iPhone 14), kiểm tra thanh điều hướng Hamburger và chụp ảnh (`screenshot-mobile.png`, `screenshot-mobile-fullpage.png`)
- Quay video tương tác người dùng: Cuộn trang, thử các tab bộ lọc món ăn, nhấn "+ Chọn món" để tự động điền vào form, nhập tên, số điện thoại, ghi chú, và nhấn submit đơn hàng
- Kiểm tra bắt sự kiện `console.log("Đơn đã gửi!", data)` và hộp thoại thông báo `alert("Đơn đã gửi!...")`

Để chạy kiểm thử tự động:
```bash
npm test
```
Hoặc:
```bash
node scripts/test_e2e.js
```
Kết quả ảnh chụp và video `.webm` sẽ được xuất tự động vào thư mục `test-artifacts/`.
